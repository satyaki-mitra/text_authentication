**System: Real-Time Weather Forecasting API**

The Real-Time Weather Forecasting API is a cloud-based platform that provides current and forecasted weather conditions for various locations around the world. This API allows developers to integrate real-time weather data into their applications, enabling users to access accurate and up-to-date weather information.

**Specifications:**

* **API Endpoints:**
	+ `/weather/current`: Returns current weather conditions (temperature, humidity, wind speed, etc.) for a specific location.
	+ `/weather/forecast`: Returns forecasted weather conditions (high and low temperatures, precipitation, etc.) for a specific location over the next 7 days.
* **API Request Methods:**
	+ HTTP GET requests are used to retrieve data from the API endpoints.
* **API Response Formats:**
	+ JSON (default) or XML formats can be specified in the `Accept` header of the request.
* **API Authentication:**
	+ API key is required for authentication. You can obtain an API key by registering on our website and creating a developer account.

**Usage Guidelines:**

1. **Authentication:** To use the API, you must first obtain an API key by registering on our website and creating a developer account.
2. **Endpoint URLs:** Use the following URLs to access the API endpoints:
	+ `https://api.weatherforecast.com/weather/current` (current weather conditions)
	+ `https://api.weatherforecast.com/weather/forecast` (weather forecast for the next 7 days)
3. **Request Parameters:**
	+ `location`: Specify the location for which you want to retrieve weather data. You can use the following formats:
		- City name (e.g., "New York")
		- Zip code (e.g., "10001")
		- Latitude and longitude coordinates (e.g., "40.7128, -74.0060")
4. **Query Parameters:**
	+ `units`: Specify the units of measurement for temperature and wind speed:
		- `imperial` (default): Fahrenheit, miles per hour
		- `metric`: Celsius, kilometers per hour
5. **Response:** The API response will contain a JSON or XML object with the requested weather data.

**Error Handling:**

* If an invalid request is made, the API will return a 400 Bad Request error response.
* If the location specified in the request cannot be found, the API will return a 404 Not Found error response.
* If any other unexpected errors occur, the API will return a 500 Internal Server Error response.

**Rate Limiting:**

* To prevent abuse and ensure fair usage of our API, we impose rate limits on requests. You can make up to 100 requests per minute, with a maximum of 10,000 requests per day.
* If you exceed these limits, the API will return a 429 Too Many Requests error response.

By following these guidelines and specifications, you can successfully integrate the Real-Time Weather Forecasting API into your applications and provide users with accurate and up-to-date weather information.

**API Endpoint: Get User Information**

### Overview

The `getUser` API endpoint allows authenticated users to retrieve their own user information, including their profile details and associated data. This endpoint is designed for use by the client-side application to populate the user's profile information.

### Request

#### Method

* **GET**: The `getUser` endpoint accepts GET requests.

#### URL**

* `https://api.example.com/users/me`

#### Headers

* **Authorization**: The API key or token required for authentication. (Required)
* **Content-Type**: Set to `application/json` to indicate the request body format.

#### Query Parameters

None

### Response

The response will be in JSON format and include the following fields:

* **id** (integer): Unique identifier for the user.
* **name** (string): The user's full name.
* **email** (string): The user's email address.
* **profile_picture** (string): A URL pointing to the user's profile picture.
* **bio** (string): A brief bio or description of the user.

Example Response:

```json
{
  "id": 123,
  "name": "John Doe",
  "email": "johndoe@example.com",
  "profile_picture": "https://example.com/picture.jpg",
  "bio": "Software engineer by day, gamer by night."
}
```

### Error Handling

The `getUser` endpoint will return the following error responses:

* **401 Unauthorized**: The request lacks valid authentication credentials.
* **404 Not Found**: The requested user does not exist or is invalid.

Error responses will be in JSON format and include an error message. For example:

```json
{
  "error": {
    "code": 401,
    "message": "Invalid API key provided."
  }
}
```

### Technical Requirements

* **HTTP**: The `getUser` endpoint supports HTTP/1.1.
* **JSON**: The response

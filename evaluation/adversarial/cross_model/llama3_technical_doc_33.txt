**Endpoint:** `/api/v1/users`

**HTTP Method:** `GET`

**Description:**

The `/api/v1/users` endpoint returns a list of all users in the system, along with their corresponding details.

**Request Parameters:**

* **None**

**Response:**

The response will be in JSON format and contain an array of user objects. Each user object will have the following properties:

* `id`: The unique identifier for the user.
* `name`: The full name of the user.
* `email`: The email address associated with the user.
* `role`: The role of the user (e.g., "admin", "moderator", "user").

Example Response:
```json
[
  {
    "id": 1,
    "name": "John Doe",
    "email": "johndoe@example.com",
    "role": "user"
  },
  {
    "id": 2,
    "name": "Jane Smith",
    "email": "janesmith@example.com",
    "role": "moderator"
  },
  {
    "id": 3,
    "name": "Bob Johnson",
    "email": "bobjohnson@example.com",
    "role": "admin"
  }
]
```
**Error Handling:**

* **400 Bad Request:** If the request is malformed or missing required parameters, a `400 Bad Request` error will be returned with an error message.
* **500 Internal Server Error:** In case of any internal server errors (e.g., database connectivity issues), a `500 Internal Server Error` will be returned.

**Security Considerations:**

* **Authentication:** This endpoint does not require authentication, as it is intended for public use. However, please note that sensitive information may still be exposed if an attacker gains access to the system.

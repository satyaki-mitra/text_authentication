**API Endpoint: Get User Information**

### Overview

This API endpoint allows clients to retrieve information about a specific user in the system. The endpoint is secured using SSL/TLS and requires authentication using an API key.

### Request Parameters

* **user_id**: A unique identifier for the user, which can be obtained from the `id` field in the response of the [Create User](#create-user) endpoint or by searching for a user using the [Search Users](#search-users) endpoint. (Required)

### Response Format

The API returns data in JSON format.

### Success Response

* **status**: A string indicating the status of the request ("OK")
* **data**: An object containing the following fields:
	+ **id**: The unique identifier for the user
	+ **name**: The name of the user
	+ **email**: The email address of the user
	+ **phone_number**: The phone number of the user (if available)
	+ **created_at**: The date and time when the user account was created

### Error Response

* **status**: A string indicating the status of the request ("ERROR")
* **error_code**: An integer error code (e.g. 404, 401, etc.)
* **error_message**: A human-readable message describing the error

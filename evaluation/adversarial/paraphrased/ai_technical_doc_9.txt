## API for User Management: Operations on Accounts

This document explains the operations supported by the `User Administration` API, which offers a RESTful interface to handle user account creation, retrieval, modification, and deletion within our system.

### Base URL

For all requests, the base URL is `https://api.example.com/v1`.

### Authentication Prerequisites

All API calls necessitate authentication via an API key in the `Authorization` header. Developers can acquire their API keys by creating accounts on our platform.

Example:
```bash
Authorization: Bearer YOUR_API_KEY
```

### Endpoints

#### 1. Registering New Users (POST /users)

Create a new user within the system.

##### Request Parameters

| Parameter     | Data Type    | Description                              | Is Required? |
|---------------|--------------|------------------------------------------|-------------|
| name          | string       | Full name of the user                    | Yes         |
| email         | string       | Unique email address for the user        | Yes         |
| password      | string (hashed)   | User's encrypted password                | Yes         |
| role          | enum         | Role assigned to the user (admin, standard, etc.) | No          |

##### Response Parameters

| Parameter    | Data Type    | Description                             |
|--------------|--------------|-----------------------------------------|
| id           | integer      | Unique identifier of the newly created user |
| name         | string       | Full name of the user                     |
| email        | string       | Unique email address for the user         |
| role         | enum         | Role assigned to the user (admin, standard, etc.) |

##### Example Request

```bash
POST /users HTTP/1.1
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY

{

    "email": "john.doe@example.com",

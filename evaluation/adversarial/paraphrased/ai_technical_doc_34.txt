Title: User Account Management API Endpoint

## API for Application User Administration

### Overview

This API offers endpoints to handle user accounts within our system. The primary functions encompass account creation, retrieval, modification, and deletion. All actions are carried out via the HTTPS protocol to ensure data protection.

### Authentication Prerequisites

All requests directed towards this endpoint necessitate a valid API key for verification. The API key must be incorporated in the `Authorization` header prefixed with `Bearer`. For instance:

```
Authorization: Bearer <your_api_key>
```

### Endpoints

#### 1. User Registration (POST /accounts)

Creates a new user account.

**Request Parameters**

| Parameter      | Data Type          | Description                                                               |
|----------------|--------------------|---------------------------------------------------------------------------|
| username       | String             | The user's full name                                                      |
| email          | String             | A distinct email address for the user                                     |
| password       | String             | The user's chosen password (encrypted before storage)                    |
| role           | Enum ('admin', 'user') | The user's role within the application (either admin or regular user)    |

**Response Parameters**

| Parameter      | Data Type          | Description                                |
|----------------|--------------------|--------------------------------------------|
| id             | Integer            | The created user's unique identifier        |
| username       | String             | The user's full name                         |
| email          | String             | The user's email address                     |
| role           | Enum ('admin', 'user') | The user's role within the application      |

POST /accounts HTTP/1.1
Content-Type: application/json
Authorization: Bearer <your_api_key>

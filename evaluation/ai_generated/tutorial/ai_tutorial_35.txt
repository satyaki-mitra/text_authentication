Title: A Step-by-Step Guide to Using Git and GitHub for Beginners

**Step 1: Installation of Git and Git Bash (for Windows) or Terminal (for Mac/Linux)**

1.1 Visit the official Git website: https://git-scm.com/

1.2 Click on the Downloads tab, then choose the latest version of Git for your operating system.

1.3 Follow the installation instructions provided by Git to install it on your computer.

**Step 2: Installation of GitHub Desktop (Optional - recommended for beginners)**

2.1 Visit the GitHub Desktop download page: https://desktop.github.com/

2.2 Click on the Download for Windows or Mac button, depending on your operating system.

2.3 Follow the installation instructions provided by GitHub to install GitHub Desktop.

**Step 3: Configuration of Git**

3.1 Open Git Bash (Windows) or Terminal (Mac/Linux).

3.2 Set your name and email for commit messages. Type the following commands in the terminal:

```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

Replace "Your Name" and "your-email@example.com" with your actual name and email address.

**Step 4: Creating a new local repository**

4.1 Navigate to the desired project directory in Git Bash or Terminal using the command `cd path/to/directory`.

4.2 Initialize a new Git repository by running the following command:

```bash
git init
```

**Step 5: Making changes and committing them**

5.1 Create a file (for example, `index.html`) in the project directory.

5.2 Check if the new file was added to Git's tracking by running the following command:

```bash
git status
```

5.3 Stage the changes you want to commit using the following command:

```bash
git add index.html
```

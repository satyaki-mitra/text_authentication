Title: A Step-by-Step Tutorial for Beginners on Using Git and GitHub

1. Installation
   - **Git**: Download the appropriate version of Git from https://git-scm.com/downloads. Follow the installation instructions for your operating system.

   - **GitHub Desktop (Optional)**: If you prefer a graphical user interface, download and install GitHub Desktop from https://desktop.github.com/.

2. Set up Git on your local machine
   - Open a terminal or command prompt and type `git config --global user.name "Your Name"`. Replace "Your Name" with your full name. This sets your username globally across all repositories.

   - Type `git config --global user.email "youremail@example.com"` and replace "youremail@example.com" with your email address. This also sets the email address globally across all repositories.

3. Verify the configuration
   - To verify that Git has saved your name and email, type `git config user.name` and `git config user.email`.

4. Initialize a new local repository
   - Navigate to the directory you want to turn into a Git repository on your computer using the command line or terminal. Type `git init` to initialize the repository there.

5. Create a file and make initial commit
   - Create a new file (e.g., `example.txt`) in the initialized repository directory.

   - Stage the file by typing `git add example.txt`. This prepares the file for the first commit.

   - Type `git commit -m "Initial commit"` to save the staged changes and create the initial commit.

6. Create a new repository on GitHub
   - Go to https://github.com and log in or sign up if you haven't already.

   - Click "Create a new repository." Give your repository a name, choose whether it is public or private, and add a brief description. Then click "Create repository."

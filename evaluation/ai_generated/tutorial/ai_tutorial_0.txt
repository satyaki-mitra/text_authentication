Title: A Step-by-Step Guide to Creating Your First Web Page using HTML and CSS

**Step 1: Setting Up the Environment**

1.1 Install a Code Editor: Download a free code editor like Visual Studio Code, Sublime Text, or Atom. These editors are beginner-friendly and easy to use.

1.2 Install Live Server Extension (for VS Code): This extension will automatically serve the HTML files for you locally so you can see your webpage in action without needing to set up a server.

**Step 2: Creating Your First HTML Document**

2.1 Open your code editor and create a new file with a `.html` extension, such as "index.html".

2.2 Add the following basic structure inside the file:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Web Page</title>
</head>
<body>
    <h1>Welcome to My First Web Page!</h1>
</body>
</html>
```

2.3 Save the file and open it in your web browser by clicking on "Open with Live Server" if you're using VS Code or following the appropriate steps for other code editors. You should now see a simple webpage displaying: "Welcome to My First Web Page!"

**Step 3: Styling Your Web Page with CSS**

3.1 In your HTML file, add the following line right before the `</head>` tag:

```html
<link rel="stylesheet" href="styles.css">
```

3.2 Create a new file called "styles.css" in the same directory as your HTML file and add some basic styling:

```css
body {
    background-color: #f0f8ff;
}

h1 {
    color: navy;
    text-align: center;
}
```

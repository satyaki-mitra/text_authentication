Title: A Step-by-Step Guide for Beginners: Creating a Simple HTML Web Page Using Notepad (Windows)

Creating a basic HTML web page can be an exciting first step into the world of web development. This tutorial will guide you through the process using Notepad on Windows. Let's get started!

**Step 1: Installation (Not Required as we're using built-in tools)**
Since we are using Notepad, which is a built-in tool in Windows, there's no need for installation. If you have Windows, you already have everything you need to create HTML files.

**Step 2: Creating a New Document**
1. Open Notepad by typing "notepad" into the Start menu and pressing Enter.
2. To create a new HTML file, click on 'File' in the top left corner, then select 'New'. A blank document will appear.

**Step 3: Writing Basic HTML Code**
HTML code consists of elements enclosed by tags. For our simple web page, we'll create an `<html>`, `<head>`, and `<body>` section, as well as some basic text.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Web Page</title>
</head>
<body>
    <h1>Welcome to My First Web Page!</h1>
    <p>This is some text for my web page.</p>
</body>
</html>
```

**Step 4: Saving the File as an HTML Document**
1. Click on 'File' in the top left corner, then select 'Save As'.
2. In the 'Save As' dialog box, navigate to your desired location for saving the file.
3. Name your file (e.g., `index.html`), ensuring it ends with ".html".
4. Choose 'All Files (*.*)' from the 'Save as type' dropdown menu.
5. Click on 'Save'.

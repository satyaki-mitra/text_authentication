**API Documentation**

## Movie Rating REST Endpoint

This document outlines the specifications for our Movie Rating REST API endpoint. The goal of this API is to allow users to rate movies, view other users' ratings, and manage their own rating history.

### Endpoint Description

The primary endpoint for our Movie Rating API is `/movies/{movieId}/rate`. This endpoint is designed to handle movie rating requests from authenticated users.

### Request Parameters

- `movieId` (required, integer): The unique identifier for the movie being rated.
- `rating` (required, float): The user's rating for the specified movie.
- `userId` (optional, integer): The unique identifier of the user performing the rating action. If not provided, the authenticated user will be assumed.

### Response Parameters

- `movieId` (integer): The unique identifier for the rated movie.
- `rating` (float): The new rating for the specified movie after the request.
- `userId` (integer): The unique identifier of the user who performed the rating action.
- `timestamp` (string, ISO 8601 format): The timestamp when the rating was submitted.

### Authentication Requirements

All requests to the Movie Rating API must be authenticated using a JSON Web Token (JWT). The JWT must be included in the `Authorization` header with the prefix "Bearer ". Unauthenticated requests will return an error response (see below for details).

### Example Requests

#### Successful Request

To rate a movie as a user, send a POST request to the following URL:

```
https://api.movierating.com/movies/{movieId}/rate
Authorization: Bearer {your_jwt_token}
Content-Type: application/json

{
  "rating": 4.5
}
```

#### Error Response

If an error occurs during the request, the API will return a JSON object with an `errorCode` and a human-readable `message`. Here's an example of a failed request:

```json
{
  "errorCode": 401,
  "message": "Unauthorized. Please provide valid authentication credentials."
}
```

### Usage Notes

- If the user attempting to rate a movie does not have an account, they will be required to create one before rating any movies.
- Ratings can only be updated once per user for each movie.
- The API will return error responses if provided `movieId` is invalid or the specified movie has already been rated by the authenticated user.

Title: Weather Forecast API Documentation

## Introduction

Welcome to the Weather Forecast API! This API provides real-time and forecasted weather data for various locations around the world.

### Endpoint Description

The main endpoint is `GET /weather` which retrieves current weather conditions and a 5-day forecast for a specified location.

### Request Parameters

| Parameter    | Data Type          | Required | Description                                                                               |
|--------------|--------------------|----------|-------------------------------------------------------------------------------------------|
| `location`   | String             | Yes      | The city name or geographical coordinates (e.g., "New York" or "40.7128,-74.0060")        |
| `units`      | String             | No       | Specify the units for temperature and wind speed. Valid values: `metric`, `imperial`, or `auto` (default) |
| `apiKey`     | String             | Yes      | A unique API key to authenticate your requests                                          |

### Authentication Requirements

To access the Weather Forecast API, you must have a valid API key. You can obtain an API key by creating an account on our website or contacting our support team. The `apiKey` should be included in every request header with the format:

```
Authorization: Bearer [YourAPIKey]
```

### Example Requests

#### Request 1 (Current Weather)

```
GET /weather?location=New%20York&units=metric HTTP/1.1
Host: api.example.com
Authorization: Bearer [YourAPIKey]
```

#### Request 2 (5-Day Forecast)

```
GET /weather?location=40.7128,-74.0060&units=imperial HTTP/1.1
Host: api.example.com
Authorization: Bearer [YourAPIKey]
```

### Response Parameters

| Parameter             | Data Type         | Description                                                                                |
|-----------------------|-------------------|--------------------------------------------------------------------------------------------|
| `location`            | String            | The requested location                                                                    |
| `current`             | Object            | Current weather data                                                                      |
| `forecast`            | Array of objects   | 5-day forecast data for the specified location                                           |
| `current.temperature` | Number            | The current temperature in the requested units (Celsius or Fahrenheit)                    |
| `current.humidity`    | Number            |

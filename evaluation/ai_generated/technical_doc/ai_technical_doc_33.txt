**API Documentation: Weather Forecast REST Endpoint**

**Endpoint Description:**

This API provides weather forecast data for a given location based on latitude and longitude coordinates.

**Base URL:** `https://weather-api.example.com/v1`

**Weather Forecast Endpoint:** `/weather-forecast`

**Authentication Requirements:**

Access to this endpoint requires an API key for authentication. The API key should be sent as a header named `X-API-Key`.

**Request Parameters:**

| Parameter      | Data Type  | Description                                             | Required |
|---------------|-----------|---------------------------------------------------------|----------|
| lat            | float     | Latitude of the location in degrees                     | Yes      |
| lng            | float     | Longitude of the location in degrees                    | Yes      |
| units          | string    | The unit system for temperature (either 'metric' or 'imperial') | No       |
| api_key        | string    | Your API key for authentication                         | Yes      |

**Example Request:**

```bash
curl -H "X-API-Key: YOUR_API_KEY" https://weather-api.example.com/v1/weather-forecast?lat=40.7128&lng=-74.0060&units=metric
```

**Response Parameters:**

| Parameter        | Data Type  | Description                                             |
|------------------|-----------|---------------------------------------------------------|
| location         | object     | Contains the name and coordinates of the location      |
| current          | object     | Current weather conditions at the given location       |
| forecast         | array      | An array of objects, each representing a future hour's weather forecast |

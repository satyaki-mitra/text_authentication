Title: API Documentation - User Management Endpoint

## 1. Introduction

This document outlines the functionality, parameters, authentication requirements, and usage notes for our REST endpoint dedicated to user management operations.

## 2. Endpoint Description

The User Management API provides a set of endpoints that enable you to create, read, update, and delete user accounts in your application. This document focuses on the `/users` endpoint.

- **Base URL:** `https://your-api-base-url.com`
- **Endpoint:** `/users`

## 3. Request Parameters

### 3.1 For POST requests (Create User)

| Parameter Name | Data Type   | Description                                       |
|----------------|------------|---------------------------------------------------|
| `name`         | `string`   | The user's full name                             |
| `email`        | `string`   | A unique email address for the user              |
| `password`     | `string`   | The user's password (encrypted before storage)  |
| `role`         | `string`   | The user's role within the system (e.g., admin, user) |

### 3.2 For GET requests (Read User)

No additional parameters are required for retrieving a specific user by its unique ID in the path.

### 3.3 For PUT/PATCH requests (Update User)

| Parameter Name | Data Type   | Description                                      |
|----------------|------------|--------------------------------------------------|
| `id`           | `integer`  | The user's unique identifier                    |
| `name`         | `string`   | The updated user's full name                    |
| `email`        | `string`   | The updated user's email address                |
| `password`     | `string`   | The updated user's password (encrypted before storage) |
| `role`         | `string`   | The updated user's role within the system       |

## 4. Response Parameters

### 4.1 For Successful Responses

| Parameter Name | Data Type    | Description                               |
|----------------|-------------|-------------------------------------------|
| `status_code`  | `integer`   | The HTTP status code (e.g., 200, 201)     |

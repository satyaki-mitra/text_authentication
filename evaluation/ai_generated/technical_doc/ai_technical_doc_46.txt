Title: **API Documentation - User Management Endpoint**

**Endpoint Description:**

The `/api/v1/users` endpoint is a RESTful API designed for managing user resources. It allows for the creation, retrieval, update, and deletion of users within the system.

**Request Methods:**
- `GET`: Retrieve a list of users
- `POST`: Create a new user
- `PUT`: Update an existing user
- `DELETE`: Delete an existing user

**Authentication Requirements:**
All requests to this endpoint require authentication. The token for authentication should be included in the `Authorization` header as a Bearer token (e.g., `Authorization: Bearer {token}`).

**Request/Response Parameters:**

1. **GET Request**
   - **Query Params:**
     - `page` *(optional, integer)*: The page number to retrieve. Default is 1.
     - `limit` *(optional, integer)*: The number of items per page. Default is 20.

   - **Response:**
     - `status` *(integer)*: HTTP status code (e.g., 200 for success)
     - `data`: An array containing user objects
       - `id` *(integer)*: The unique identifier of the user
       - `username` *(string)*: The username of the user
       - `email` *(string)*: The email address of the user
       - `first_name` *(string)*: The first name of the user
       - `last_name` *(string)*: The last name of the user
     - `message` *(string)*: A brief message describing the response (e.g., "Users fetched successfully.")

2. **POST Request**
   - **Request Body:**
     - `username` *(string, required)*: The desired username for the new user
     - `email` *(string, required)*: The email address of the new user
     - `password` *(string, required)*: The password for the new user (encrypted)
     - `first_name` *(string, optional)*: The first name of the new user
     - `last_name` *(string, optional)*: The last name of the new user

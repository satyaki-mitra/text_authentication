Title: Pet Store REST API Documentation

## Pet Store API Overview

The Pet Store API is a RESTful service designed for managing pet-related resources such as pets, stores, and orders. This documentation provides an overview of the API's primary endpoint for creating, retrieving, updating, and deleting pet resources.

### Base URL

All endpoints in this API are accessible under the base URL `https://petstore.swagger.io/v2`.

## Pets Endpoint

### Description

The `/pet` endpoint is used to manage various pet-related operations, including creating, retrieving, updating, and deleting pets.

### Request Parameters

#### Query Parameters (Optional)

| Parameter | Data Type  | Description                                               |
|-----------|-----------|-----------------------------------------------------------|
| `status`  | `string`  | Filter pets by their status (available or sold)            |
| `limit`   | `number`  | Limit the number of results returned per request           |
| `offset`  | `number`  | Offset the starting point for results in the response      |

#### Path Parameters (Optional)

| Parameter | Data Type  | Description                        |
|-----------|-----------|------------------------------------|
| `petId`   | `string`  | Unique identifier for a specific pet |

### Request Body (POST, PUT)

| Property       | Data Type            | Description                                                      |
|---------------|---------------------|------------------------------------------------------------------|
| `id`          | `string`            | Unique identifier for the pet (optional if creating a new pet)  |
| `categoryId`  | `string`            | Identifier of the category to which the pet belongs             |
| `status`      | `enum(available, sold)` | Current status of the pet                                       |
| `name`        | `string`            | Name of the pet                                                  |
| `photoUrls`   | `array<string>`     | URLs for photos of the pet                                      |
| `tags`        | `array<object>`     | Array of tags associated with the pet (see below)                |
| `category`    | `object`           | Object containing details about the pet's category (see below)   |

**Tag object:**
```json
{
  "id": "string",
  "name": "string"
}
```

**Category object:**
```json
{
  "id": "string",
  "name": "string"
}
```

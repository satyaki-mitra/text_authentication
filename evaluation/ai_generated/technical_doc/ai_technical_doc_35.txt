Title: API Documentation - User Management Endpoint

## User Management Endpoint

This document describes the `User Management` REST endpoint of our API. The endpoint is used to create, retrieve, update, and delete user accounts.

### Endpoint Description

**Base URL:** `https://api.example.com/v1`

**Endpoint:** `/users`

### Request Parameters

#### HTTP Verbs

- `GET`: Retrieve a list of users (paginated).
- `POST`: Create a new user account.
- `PUT`: Update an existing user account.
- `DELETE`: Delete an existing user account.

#### Query Parameters for GET requests

| Name      | Type   | Description                             | Default Value | Required |
|-----------|--------|-----------------------------------------|---------------|----------|
| limit     | integer | Maximum number of users per page response| 20            | False    |
| offset    | integer | The starting index for the paginated list| 0             | False    |
| sort      | string  | Sorting order (asc or desc)             | asc           | False    |
| direction | string  | Direction of the sort (column name)     | none          | False    |

#### Request Body for POST, PUT requests

| Name      | Type   | Description                                                               | Required |
|-----------|--------|---------------------------------------------------------------------------|----------|
| id        | string  | Unique identifier of the user (auto-generated on creation)               | False    |
| username  | string  | Username for the account (must be unique)                                  | True     |
| password  | string  | Password for the account (securely stored, never sent over API)           | True     |
| email     | string  | Email address for the user (must be unique and valid)                      | True     |
| firstName | string  | First name of the user                                                    | False    |
| lastName  | string  | Last name of the user                                                     | False    |
| roles     | array   | List of roles associated with the user (comma-separated)                | False    |

### Response Parameters

#### Success Response for GET, POST requests

| Name      | Type   | Description                             |
|-----------|--------|-----------------------------------------|
| users     | array  | List of user objects                    |
| total     | integer| Total number of users (for pagination)  |

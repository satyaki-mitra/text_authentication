Title: API Documentation - User Management Endpoint

## User Management Endpoint

The `User Management` endpoint is designed to manage user accounts within our system. This RESTful API provides several endpoints for creating, reading, updating, and deleting user accounts.

### Base URL

All requests should be made to the following base URL: `https://api.example.com/v1`

### Authentication Requirements

All requests require an access token for authentication. The token should be included in the `Authorization` header with the prefix `Bearer`. Access tokens can be obtained through our [Authentication API](authentication.md).

### Endpoints

#### 1. Create User

**Endpoint:** `POST /users`

**Request Parameters:**

- `name` (string, required) - The user's name.
- `email` (string, required, unique) - A unique email address for the user.
- `password` (string, required) - The user's password (hash is stored in database).

**Example Request:**

```bash
POST /users HTTP/1.1
Host: api.example.com
Authorization: Bearer <access_token>
Content-Type: application/json

{
  "name": "John Doe",
  "email": "john.doe@example.com",
  "password": "securepassword"
}
```

**Response:**

- `201 Created` - Upon successful creation, a new user object is returned.

**User Object Example:**

```json
{
  "id": 1,
  "name": "John Doe",
  "email": "john.doe@example.com"
}
```

#### 2. Get User by ID

**Endpoint:** `GET /users/{id}`

**Request Parameters:**

- `id` (integer, required) - The unique identifier of the user.

**Example Request:**

```bash
GET /users/1 HTTP/1.1
Host: api.example.com
Authorization: Bearer <access_token>
```

**Response:**

- `200 OK` - If the user exists, the user object is returned.
- `404 Not Found` - If the user does not exist.

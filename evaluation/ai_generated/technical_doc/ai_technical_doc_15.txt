Title: **API Documentation - User Management Endpoint**

## User Management API

### Endpoint Description

The `User Management API` provides a RESTful interface to create, retrieve, update, and delete user accounts within the system. The primary endpoint for this service is `/api/users`.

### Request Parameters

#### Create User (POST)

- `Content-Type: application/json`

```json
{
  "username": "<string>",
  "password": "<string>",
  "email": "<string>",
  "first_name": "<string>",
  "last_name": "<string>"
}
```

#### Retrieve User (GET)

- `Accept: application/json`
- Optional query parameters: `?id=<integer>`, `?username=<string>`, `?email=<string>`

#### Update User (PUT)

- `Content-Type: application/json`
- Required query parameter: `id=<integer>`

```json
{
  "username": "<optional string>",
  "password": "<optional string>",
  "email": "<optional string>",
  "first_name": "<optional string>",
  "last_name": "<optional string>"
}
```

#### Delete User (DELETE)

- Required query parameter: `id=<integer>`

### Response Parameters

#### Successful Response

- Status Code: **200 OK**
- Content Type: `application/json`

```json
{
  "id": <integer>,
  "username": "<string>",
  "email": "<string>",
  "first_name": "<string>",
  "last_name": "<string>"
}
```

#### Error Response

- Status Code: **400 Bad Request**, **401 Unauthorized**, **404 Not Found**, or **500 Internal Server Error**
- Content Type: `application/json`

```json
{
  "error_code": <integer>,
  "message": "<error description>"
}
```

### Authentication Requirements

All actions except for retrieving a user by ID require authentication. Use the provided API key in the `Authorization` header as follows:

- `Authorization: Bearer <API_KEY>`

### Usage Notes

- When creating a new user, ensure that the provided username, email, and password are unique within the system.

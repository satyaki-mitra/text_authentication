**API Documentation**

Title: User Management API

Description: This API provides endpoints for managing user-related operations such as registration, login, profile update, and more.

## Endpoints

### User Registration

#### Request

```http
POST /api/users
Content-Type: application/json
```

#### Parameters

| Name      | Type   | Description                                             | Required | Example                         |
| --------- | ------ | ------------------------------------------------------- | -------- | ------------------------------- |
| username  | string | A unique identifier for the user.                       | Yes      | "john_doe"                      |
| email     | string | The user's email address, used for password recovery.   | Yes      | "johndoe@example.com"          |
| password  | string | The user's secure password, encrypted before storage.  | Yes      | "secure_password_hash"          |
| firstName | string | The user's first name.                                  | No       | "John"                          |
| lastName  | string | The user's last name.                                   | No       | "Doe"                           |

#### Response

```http
HTTP/1.1 201 Created
Content-Type: application/json

{
  "user_id": 1,
  "username": "john_doe",
  "email": "johndoe@example.com"
}
```

#### Authentication Requirements

None for this endpoint as it is used for user registration and does not require an existing user account.

### User Login

#### Request

```http
POST /api/users/login
Content-Type: application/json
```

#### Parameters

| Name     | Type   | Description                                        | Required | Example                         |
| -------- | ------ | --------------------------------------------------| -------- | ------------------------------- |
| email    | string | The user's email address used for authentication.  | Yes      | "johndoe@example.com"          |
| password | string | The user's secure password, encrypted before use.  | Yes      | "secure_password_hash"          |

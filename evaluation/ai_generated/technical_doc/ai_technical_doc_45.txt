**API Documentation: Weather Forecast REST Endpoint**

**Endpoint Description:**

This API provides weather forecast information for a given location. The endpoint uses OpenWeatherMap's API to fetch the data.

**Base URL:** `https://api.your-app.com/v1`

**Endpoint:** `/weather_forecast`

**Authentication Requirements:**

Access to this endpoint requires an API key. The key should be included in every request as a header, with the name "Authorization".

**Request Parameters:**

- **location (required)** : The location for which you want to fetch the weather forecast. It can be either a city name or a geographical coordinate in the format of `latitude,longitude`.
  - Data Type: String or GeoJson Point

- **units (optional)** : The type of units for the temperature. Supported values are "metric" and "imperial". Default is "metric".
  - Data Type: String

**Example Requests:**

1. To fetch weather forecast for London, use the following request:

```bash
GET /weather_forecast?location=London HTTP/1.1
Authorization: Api-Key Your-API-Key
```

2. To fetch weather forecast for coordinates (37.7749, -122.4194) and use imperial units, use the following request:

```bash
GET /weather_forecast?location=37.7749,-122.4194&units=imperial HTTP/1.1
Authorization: Api-Key Your-API-Key
```

**Response Parameters:**

- **status (required)** : The status of the request. Can be either "success" or "error".
  - Data Type: String

- **data (required)** : An object containing the weather forecast information if the request was successful, or an error message if the request failed.
  - Data Type: Object

    * **forecast** : An array of objects, each representing a day's forecast.
      - Data Type: Array of JSON objects

        * **date** : The date for which the forecast is provided.
          - Data Type: String (ISO 8601 formatted)

        * **temperature** : The temperature for the given date, in the units specified in the request.
          - Data Type: Number

        * **weather_description** : A description of the weather conditions for the given date.
          - Data Type: String

    * **error (if status is "error")** : A human-readable error

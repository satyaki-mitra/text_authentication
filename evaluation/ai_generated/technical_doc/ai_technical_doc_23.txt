Title: API Documentation - User Management Endpoints

## 1. User Endpoint Overview

This documentation outlines the REST endpoint for user management operations in our API. The base URL for all user-related endpoints is `https://api.example.com/v1`.

## 2. Endpoints Description

### 2.1 Create a New User (POST /users)

Create a new user in the system. Only authorized admin users can create new users.

### 2.2 Retrieve User Profile (GET /users/:userId)

Retrieve detailed information about an existing user by their unique identifier. Any authenticated user can access their own profile and admins can access all profiles.

### 2.3 Update User Profile (PUT /users/:userId)

Update the details of an existing user by their unique identifier. Only the user themselves or authorized admin users can update a user's profile.

### 2.4 Delete User Account (DELETE /users/:userId)

Delete an existing user account by their unique identifier. Only authorized admin users can delete user accounts.

## 3. Request/Response Parameters

### 3.1 Common Parameters

- `Authorization`: Bearer {token} (JWT token for authentication)
- `Content-Type`: application/json

### 3.2 Create User Parameters (POST /users)

Request Body Example:
```json
{
    "firstName": "John",
    "lastName": "Doe",
    "email": "john.doe@example.com",
    "password": "secure_password"
}
```
- `firstName` (string, required) - The first name of the user.
- `lastName` (string, required) - The last name of the user.
- `email` (string, required, unique) - The email address of the user.
- `password` (string, required) - The password for the user's account.

### 3.3 Retrieve User Profile Parameters (GET /users/:userId)

Path Parameter:
- `userId` (integer, required) - The unique identifier of the user to retrieve.

Response Body Example:
```json
{
    "id": 1,
    "firstName": "John",
    "lastName": "Doe",
    "email": "john.doe@example.com"
}
```

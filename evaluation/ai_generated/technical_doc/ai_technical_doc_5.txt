Title: API Documentation - User Management Endpoint

## User Management Endpoint

### Description

This API provides a RESTful endpoint for managing user accounts within our system. The `/users` endpoint allows you to create new users, retrieve user details, update existing users, and delete users.

### Authentication Requirements

All requests to the User Management Endpoint require an access token as part of the Authorization header. The token should be provided in the format: `Authorization: Bearer {access_token}`. Access tokens can be obtained through the Authentication API.

### Endpoint

`POST /users` - Create a new user
`GET /users/{userId}` - Retrieve user details
`PUT /users/{userId}` - Update an existing user
`DELETE /users/{userId}` - Delete a user

### Request Parameters

#### `POST /users` - Create User

**Request Body:** (application/json)

| Name       | Data Type | Description                                   | Required |
|------------|----------|-----------------------------------------------|----------|
| username   | string   | The unique identifier for the user account.  | Yes      |
| password   | string   | The encrypted password for the user account.  | Yes      |
| email      | string   | A valid email address for the user account.   | Yes      |

#### `GET /users/{userId}` - Retrieve User Details

**URL Parameters:**

- `userId`: (integer) The unique identifier of the requested user.

**Response Body:** (application/json)

| Name         | Data Type    | Description                                                       |
|--------------|-------------|-------------------------------------------------------------------|
| id           | integer      | The unique identifier for the user account.                        |
| username     | string       | The username of the user account.                                  |
| email        | string       | The email address associated with the user account.                |
| createdAt    | date-time    | The timestamp when the user account was created.                   |
| updatedAt    | date-time    | The timestamp when the user account was last updated.              |

#### `PUT /users/{userId}` - Update User

**Request Body:** (application/json)

| Name       | Data Type | Description                           | Required |
|------------|----------|---------------------------------------|----------|
| username   | string   | The new username for the user account. | No       |
| password   | string   | The encrypted new password for the user account. | No       |
| email      | string   | A new valid email address for the user account. | No       |

Title: API Documentation - User Management Endpoint

## User Management REST Endpoint

### Description

This API provides endpoints for managing user accounts within our system. The main functionalities include creating, retrieving, updating, and deleting user records. All requests are made over HTTPS using the REST architecture.

### Authentication Requirements

All requests to this endpoint require authentication. Use an API key as the authentication method. The API key should be provided in the `Authorization` header with the format: `Authorization: Bearer <API_KEY>`.

### Endpoints

#### Create User (POST)

```
https://api.example.com/users
```

Create a new user account.

**Request Parameters:**

- `name` (string, required) - The full name of the user
- `email` (string, required) - A unique email address for the user
- `password` (string, required) - The password for the user's account
- `api_key` (string, required) - The API key for authentication

**Response Parameters:**

- `status` (number, 201 on success, other error codes for failure)
- `data` (object) - Contains the details of the newly created user if successful.
  - `id` (integer) - Unique identifier for the user
  - `name` (string) - The full name of the user
  - `email` (string) - The email address of the user

#### Get User (GET)

```
https://api.example.com/users/{user_id}
```

Retrieve details about a specific user.

**Request Parameters:**

- `user_id` (integer, required) - The unique identifier for the desired user
- `api_key` (string, required) - The API key for authentication

**Response Parameters:**

- `status` (number, 200 on success, other error codes for failure)
- `data` (object) - Contains the details of the requested user if successful.
  - `id` (integer) - Unique identifier for the user
  - `name` (string) - The full name of the user
  - `email` (string) - The email address of the user

#### Update User (PUT)

```
https://api.example.com/users/{user_id}
```

Update the details of an existing user.

**Request Parameters:**

- `user_id` (integer, required) - The unique identifier for the desired user
- `name` (string, optional) - The new full name

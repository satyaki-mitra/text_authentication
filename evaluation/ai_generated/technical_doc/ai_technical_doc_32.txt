Title: API Documentation - User Registration Endpoint

## User Registration Endpoint

### Description

This API provides a RESTful endpoint for user registration. The endpoint accepts POST requests containing user credentials to create a new account in the system.

### Endpoint URL

`https://api.example.com/v1/users/register`

### Request Parameters

| Parameter Name | Data Type  | Description                                       | Required | Example                         |
|---------------|-----------|--------------------------------------------------|----------|---------------------------------|
| username      | String    | Unique identifier for the user account           | Yes      | `john_doe`                      |
| email         | String    | Unique email address for the user account        | Yes      | `john.doe@example.com`         |
| password      | String    | The password for the user's account              | Yes      | `securePassword123`             |
| first_name    | String    | The user's first name                            | No       | `John`                          |
| last_name     | String    | The user's last name                             | No       | `Doe`                           |

### Authentication Requirements

This endpoint does not require authentication. However, subsequent API calls may require an access token, which will be issued upon successful registration.

### Example Request

```bash
POST https://api.example.com/v1/users/register HTTP/1.1
Content-Type: application/json

{
  "username": "john_doe",
  "email": "john.doe@example.com",
  "password": "securePassword123",
  "first_name": "John",
  "last_name": "Doe"
}
```

### Response Parameters

| Parameter Name | Data Type   | Description                           |
|---------------|------------|---------------------------------------|
| status        | Integer    | HTTP status code                     |
| message       | String     | Human-readable error or success message|
| data          | Object     | Additional data if the request is successful|

### Error Codes

| Error Code  | Description             |
|------------|-------------------------|
| 200        | Successful registration  |
| 400        | Bad Request (invalid input) |
| 409        | Conflict (username or email already exists) |
| 500        | Internal Server Error   |

### Usage Notes

1. The API will return a JSON object with the HTTP status code

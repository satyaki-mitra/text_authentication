Title: API Documentation - User Management Endpoint

## User Management REST Endpoint

### Description

This API provides a RESTful interface for managing user accounts within our system. The endpoint is designed to perform various operations such as creating, retrieving, updating, and deleting users.

### Endpoint

`POST /api/v1/users` - Create a new user
`GET /api/v1/users/{id}` - Retrieve user details by ID
`PUT /api/v1/users/{id}` - Update user details by ID
`DELETE /api/v1/users/{id}` - Delete user by ID

### Request Parameters

#### Create User (POST)

```json
{
  "firstName": "string",
  "lastName": "string",
  "email": "string",
  "password": "string"
}
```

#### Retrieve, Update, Delete User (GET/PUT/DELETE)

```json
{
  "id": "integer"
}
```

### Response Parameters

#### Success Response (200 OK)

For successful operations, the response will contain the requested data in JSON format.

##### Create User

```json
{
  "id": "integer",
  "firstName": "string",
  "lastName": "string",
  "email": "string",
  "createdAt": "date-time",
  "updatedAt": "date-time"
}
```

##### Retrieve User

```json
{
  "id": "integer",
  "firstName": "string",
  "lastName": "string",
  "email": "string",
  "createdAt": "date-time",
  "updatedAt": "date-time"
}
```

##### Update User

Same as Retrieve User response, but includes additional `updatedAt` field.

#### Error Response (4xx/5xx)

Error responses will contain a JSON object with an error code and message.

```json
{
  "errorCode": "integer",
  "message": "string"
}
```

### Authentication Requirements

All requests to the User Management endpoint require authentication using API keys. The API key should be included in the `Authorization` header of each request as follows:

```bash
Authorization: Bearer [Your API Key]
```

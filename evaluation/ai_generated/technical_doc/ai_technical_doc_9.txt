Title: API Documentation - User Management Endpoint

## User Management Endpoint

The `User Management` endpoint provides a RESTful interface for creating, reading, updating, and deleting user accounts in our system. This document outlines the details of each operation supported by this endpoint.

### Base URL

All requests should be directed to the base URL: `https://api.example.com/v1`

### Authentication Requirements

All API calls require authentication using an API key in the `Authorization` header. The API key can be obtained by registering a developer account on our platform.

Example:
```bash
Authorization: Bearer YOUR_API_KEY
```

### Endpoints

#### 1. Create User (POST /users)

Create a new user in the system.

##### Request Parameters

| Parameter      | Data Type    | Description                               | Required |
| -------------- | ------------ | ----------------------------------------- | -------- |
| name           | string       | The user's full name                      | Yes      |
| email          | string       | A unique email address for the user       | Yes      |
| password       | string       | The user's password (must be hashed)      | Yes      |
| role           | enum         | The user's role (admin, standard, etc.)   | No       |

##### Response Parameters

| Parameter  | Data Type    | Description                               |
| ---------- | ------------ | ----------------------------------------- |
| id         | integer      | The newly created user's unique identifier |
| name       | string       | The user's full name                      |
| email      | string       | A unique email address for the user       |
| role       | enum         | The user's role (admin, standard, etc.)   |

##### Example Request

```bash
POST /users HTTP/1.1
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY

{
    "name": "John Doe",
    "email": "john.doe@example.com",
    "password": "hashed_password",
    "role": "admin"
}
```

##### Error Codes

| Code | Description                       |
|------|-----------------------------------|
| 401   | Unauthorized: Invalid or missing API key      |
| 422   | Unprocessable Entity: Invalid request data format |

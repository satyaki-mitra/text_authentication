Title: Product API Documentation

## Endpoint Description

The `/products` endpoint provides a RESTful interface for managing product resources in our system. This endpoint supports CRUD (Create, Read, Update, Delete) operations on products.

## Request Parameters

### HTTP Methods

- **GET** : Retrieve a list of all products or retrieve specific product by ID.
- **POST** : Create a new product.
- **PUT** : Update an existing product.
- **DELETE** : Delete an existing product.

### Request Body Parameters (for POST and PUT requests)

| Parameter       | Data Type         | Description                                                                                                |
|-----------------|-------------------|------------------------------------------------------------------------------------------------------------|
| id              | integer           | Unique identifier for the product. Required when updating an existing product.                             |
| name            | string            | Name of the product.                                                                                      |
| description     | string            | Description of the product.                                                                               |
| price           | float             | Price of the product in USD.                                                                              |
| stock           | integer           | Current stock quantity of the product.                                                                    |
| category_id     | integer           | ID of the product's category.                                                                             |

### Query Parameters (for GET requests)

| Parameter   | Data Type | Description                                | Default Value        |
|------------|----------|--------------------------------------------|-----------------------|
| id         | integer  | Filter results by product ID.              | None (all products)   |
| limit      | integer  | Limit the number of returned products.     | 20                    |
| offset     | integer  | Offset the starting point of returned data. | 0                     |

## Response Parameters

### Success Response (2xx)

- **Status** : HTTP status code indicating success.
- **Data**   : The response data, e.g., list of products or a single product object.

### Error Responses (4xx and 5xx)

- **Status** : HTTP status code indicating an error.
- **Message** : A human-readable description of the error.

## Authentication Requirements

All requests to this endpoint require an API key for authentication. The API key should be included in the `Authorization` header with the format: `API_KEY <your_api_key>`.

## Example Requests

### Get all products (limit=20, offset=0)

```bash
GET /products HTTP/1.1
Host: your-domain.com

Title: Petstore API - Find Pets by Status

## Endpoint Description

`GET /v2/pet/findByStatus`

This endpoint allows users to search for pets based on their status (available or sold).

## Request Parameters

| Parameter      | Description                                                                     | Data Type    | Required | Default Value |
| -------------- | ------------------------------------------------------------------------------- | ------------ | -------- | ------------- |
| `status`       | The status of the pets to be returned. Supported values are 'available' and 'sold'. | string       | Yes      | -             |
| `page`         | The page number of results to return. Default is 0.                          | integer      | No       | 0             |
| `limit`        | The maximum number of items per page. Default is 20, max allowed limit is 100.  | integer      | No       | 20            |

## Response Parameters

| Parameter      | Description                                                         | Data Type    |
| -------------- | ------------------------------------------------------------------- | ------------ |
| `page`         | The current page number in the result set.                        | integer      |
| `size`         | The total number of results returned in the response.             | integer      |
| `total`        | The total number of pets found based on the given query.          | integer      |
| `pets`         | An array of pet objects that match the specified status filter.  | array        |
| `pet` (nested) | A single pet object containing information about the pet.         | object       |
|                  | - `id`                : The unique identifier for a pet            | integer      |
|                  | - `categoryId`        : The unique identifier for a pet's category | integer      |
|                  | - `categoryName`      : The name of the pet's category             | string       |
|                  | - `price`             : The price of the pet in cents              | float        |
|                  | - `status`            : The status of the pet (available or sold)    | string       |
|                  | - `name`              : The name of the pet                          | string       |
|                  | - `photoUrls`         : An array of URLs for photos of the pet      | array        |

## Authentication Requirements

API key authentication is required to access this endpoint. The API key should be included in the `Authorization` header with the prefix `api_key`.

Example:
```
Authorization: api_key <YOUR_API_KEY>

**API Documentation - User Management Endpoint**

## User Management REST Endpoint

### Overview

This API provides a RESTful interface for managing user accounts within our system. The endpoint is designed to handle various operations such as user registration, login, and profile updates.

### Endpoint Description

The base URL for all user management requests is `https://api.example.com/users`. All endpoints are HTTPS secured and support JSON data format.

### Authentication Requirements

Most of the endpoints require authentication. You can authenticate by including an API key in the `Authorization` header of your request, with the following format: `API_KEY Your-Api-Key`.

### Request/Response Parameters

| Endpoint                | HTTP Verb | Path Parameters   | Query Parameters     | Request Body         | Response Body       | Data Type            | Description                                                                                    |
|-------------------------|-----------|-------------------|----------------------|-----------------------|---------------------|---------------------|----------------------------------------------------------------------------------------------|
| Register                | POST      |                   | username, email, password | json                  | 201 Created         | JSON Object        | Creates a new user account                                                                    |
| Login                   | POST      |                   |                       | json (email, password) | 200 OK              | JSON Object        | Authenticates the user and returns an API key for future requests                           |
| Get User Profile        | GET       | username          |                       | None                  | 200 OK              | JSON Object        | Retrieves the current user's profile data                                                    |
| Update User Profile     | PATCH     | username          |                       | json (updated profile) | 200 OK              | JSON Object        | Updates the current user's profile data                                                      |

### Example Requests

#### Registering a new user:

```bash
POST https://api.example.com/users
Content-Type: application/json
Authorization: API_KEY Your-Api-Key

{
    "username": "newuser",
    "email": "newuser@example.com",
    "password": "securepassword"
}
```

#### Logging in to get an API key:

```bash
POST https://api.example.com/users/login
Content-Type: application/json

{
    "email": "newuser@example.com",
    "password": "securepassword"
}
```

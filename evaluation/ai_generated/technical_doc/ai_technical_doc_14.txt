**API Documentation - Weather Forecast Service**

**Endpoint Description:**

This API provides weather forecast information for a given location. It uses OpenWeatherMap as the primary data source.

**Base URL:** `https://weather-api.example.com/v1`

**Endpoints:**

1. **Get Weather Forecast**
   - Method: `GET`
   - Endpoint: `/forecast`

**Request Parameters:**

| Parameter     | Data Type  | Description                                                                           | Required |
|---------------|-----------|---------------------------------------------------------------------------------------|----------|
| location      | String    | The location for which to get the weather forecast. Example: "New York, NY"          | Yes      |
| units         | String    | The unit system for the temperature and wind speed. Supported values are `metric` and `imperial`. Default is `metric`  | No       |
| api_key       | String    | Your API key for authentication. Obtain it from [OpenWeatherMap](https://openweathermap.org/api)  | Yes      |

**Example Request:**

```bash
GET https://weather-api.example.com/v1/forecast?location=New+York,NY&units=imperial&api_key=YOUR_API_KEY
```

**Response Parameters:**

| Parameter    | Data Type  | Description                                                                |
|--------------|-----------|----------------------------------------------------------------------------|
| location     | String    | The requested location                                                      |
| temperature  | Number    | The current temperature in the requested unit system                         |
| humidity     | Number    | The current humidity in percentage                                           |
| wind_speed   | Number    | The current wind speed in miles per hour or meters per second, depending on units |
| forecast     | Array     | An array of forecasts for the next 5 days, each containing a date, temperature and description |

**Error Codes:**

| Code     | Description                               |
|----------|-------------------------------------------|
| 401      | Unauthorized - Invalid or missing API key |
| 404      | Not Found - Invalid location              |

**Usage Notes:**

- Replace `YOUR_API_KEY` with your actual API key obtained from OpenWeatherMap.
- The forecast includes the date, temperature, and a brief description of the weather condition for each day.
- For more information on OpenWeatherMap data structure, please refer to their [documentation](https://openweathermap.org/

**API Documentation: User Management REST Endpoint**

**Endpoint Description:**

This API provides an endpoint for managing user accounts within the application. The endpoint uses HTTPS and follows the REST architecture.

**Endpoint URL:**
`https://your-api.com/api/v1/users`

**Authentication Requirements:**
All requests to this endpoint require authentication using JSON Web Tokens (JWT). An authorized JWT must be included in the `Authorization` header of every request as a Bearer token.

**Request Parameters:**

- **Method:** `GET`, `POST`, `PUT`, `DELETE`
- **Headers:**
  - `Content-Type: application/json` (for POST and PUT requests)
  - `Authorization: Bearer {your_token}` (required for all requests)

**Response Parameters:**

- **Status Code:** The HTTP status code returned by the server. Successful responses use codes in the 2xx range, while errors return codes in the 4xx or 5xx ranges.
- **Data:** A JSON object containing response data (if applicable).

**Example Requests:**

1. **Get User by ID (GET):**
   ```
   GET https://your-api.com/api/v1/users/{user_id}
   Authorization: Bearer {your_token}
   ```
2. **Create a New User (POST):**
   ```
   POST https://your-api.com/api/v1/users
   Content-Type: application/json
   Authorization: Bearer {your_token}
   {
       "username": "newuser",
       "email": "newuser@example.com",
       "password": "password123"
   }
   ```
3. **Update a User (PUT):**
   ```
   PUT https://your-api.com/api/v1/users/{user_id}
   Content-Type: application/json
   Authorization: Bearer {your_token}
   {
       "username": "updateduser",
       "email": "updateduser@example.com"
   }
   ```
4. **Delete a User (DELETE):**
   ```
   DELETE https://your-api.com/api/v1/users/{user_id}
   Authorization: Bearer {your_token}
   ```

- `401 Unauthorized` - Missing or invalid authentication token.

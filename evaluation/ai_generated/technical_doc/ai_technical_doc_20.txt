Title: PetStore API - Adopt a Pet Endpoint

## Adopt a Pet Endpoint

The `Adopt a Pet` endpoint allows clients to adopt pets from the PetStore. This is a POST request that initiates the adoption process for a specific pet.

### Endpoint Description

`POST /store/pets/{petId}/adopt`

### Request Parameters

#### Required:
- `petId` (string): The unique identifier of the pet to be adopted. This is found in the `id` field of the pet's response from the `GET /store/pets` endpoint.

#### Optional:
- `customerName` (string): The name of the customer adopting the pet. If not provided, the default system-generated customer name will be used.

### Response Parameters

#### Success Response (200 OK):
- `petId` (string): The unique identifier of the adopted pet. This will match the provided `petId`.
- `customerName` (string): The name of the customer who adopted the pet. If not provided in the request, this field contains the default system-generated customer name.
- `status` (string): A success message confirming the adoption. Example: "Pet successfully adopted by {customerName}."

#### Error Response (400 Bad Request):
- `errorCode` (integer): A unique error code to identify the type of error that occurred. See the [Error Codes](#error-codes) section for more details.
- `message` (string): A human-readable description of the error that occurred.

### Authentication Requirements

This endpoint requires authentication using an API key. The API key should be included in the request header with the key `x-api-key`.

### Example Requests

#### Successful Adoption Request:
```bash
POST /store/pets/1234567890 HTTP/1.1
Host: mypetstore.com
x-api-key: your_api_key_here
Content-Type: application/json

{
  "customerName": "John Doe"
}
```

#### Successful Adoption Request (with default customer name):
```bash
POST /store/pets/1234567890 HTTP/1.1
Host: mypetstore.com
x-api-key: your_api_key_here
Content-Type: application/json
```

### Error Codes

| Error Code | Description                                     |
|------------|-------------------------------------------------|
| 4001       | Invalid API Key

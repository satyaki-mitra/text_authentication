Title: PetStore API - Order Resource

## Endpoint Description

The `POST /order` endpoint is used to create a new order in the PetStore. This endpoint requires proper authorization to ensure that only authorized users can place orders.

## Request Parameters

| Parameter          | Data Type  | Description                                                                                   |
|--------------------|-----------|-----------------------------------------------------------------------------------------------|
| `orderId`          | String    | Unique identifier for the order. If not provided, a unique ID will be auto-generated.      |
| `customerId`       | Number    | The ID of the customer placing the order.                                                  |
| `petId`            | Number    | The ID of the pet being purchased.                                                          |
| `quantity`         | Number    | The quantity of the pet being ordered.                                                     |
| `shipDate`         | String (date-time format: yyyy-MM-dd'T'HH:mm:ss.SSSZ) | The expected delivery date for the order, if provided. If not provided, the current date will be used. |

## Authentication Requirements

All requests to this endpoint must include an `Authorization` header with a valid token. The token should be obtained through authentication using the `POST /auth/login` endpoint.

Example:
```
Authorization: Bearer {token}
```

## Example Request

A successful request to create a new order might look like this:

```bash
POST /order HTTP/1.1
Host: petstore.swagger.io
Content-Type: application/json
Accept: application/json
Authorization: Bearer {token}

{
  "orderId": "12345",
  "customerId": 1,
  "petId": 1,
  "quantity": 2,
  "shipDate": "2022-01-01T00:00:00.000Z"
}
```

## Response

The response will contain the details of the created order. If the order creation is successful, the response will have a `200 OK` status code and include the following JSON structure:

```json
{
  "orderId": "12345",
  "customerId": 1,
  "petId": 1,
  "quantity": 2,
  "shipDate": "2022-01-01T00:00:00.000Z",
  "status": "Pending"
}
```

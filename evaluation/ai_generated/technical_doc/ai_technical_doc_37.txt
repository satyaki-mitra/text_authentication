Title: **API Documentation - User Management Endpoint**

## User Management API

The User Management API provides a set of endpoints for managing user accounts in our system. This documentation details the `/users` endpoint, which allows for creating, retrieving, updating, and deleting user accounts.

### /users (CRUD Operations)

#### Create User (POST)

Creates a new user account.

**Request Parameters:**

- `username`: **string** - The unique username for the user.
- `password`: **string** - The password for the user, encrypted before sending.
- `email`: **string** - The email address of the user.
- `first_name`: **string** - The first name of the user.
- `last_name`: **string** - The last name of the user.

##### Example Request:

```http
POST /users
Content-Type: application/json

{
  "username": "johndoe",
  "password": "encrypted_password",
  "email": "john.doe@example.com",
  "first_name": "John",
  "last_name": "Doe"
}
```

#### Retrieve User (GET)

Retrieves the details of a user by their unique username.

**Request Parameters:**

- `username`: **string** - The unique username of the user to retrieve.

##### Example Request:

```http
GET /users/johndoe
```

#### Update User (PUT)

Updates the details of an existing user by their unique username.

**Request Parameters:**

- `username`: **string** - The unique username of the user to update.
- `password`: **string** - The new password for the user, encrypted before sending (optional).
- `email`: **string** - The new email address of the user (optional).
- `first_name`: **string** - The new first name of the user (optional).
- `last_name`: **string** - The new last name of the user (optional).

##### Example Request:

```http
PUT /users/johndoe
Content-Type: application/json

{
  "password": "new_encrypted_password",
  "email": "john.doe@newemail.com"
}
```

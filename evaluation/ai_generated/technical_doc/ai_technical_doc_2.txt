Title: API Documentation - User Management Endpoint

## User Management Endpoint

The `User Management` endpoint is designed to manage user accounts within the system. This endpoint uses RESTful principles and requires HTTPS for secure communication.

### Endpoint Description

`POST /api/v1/users` - Create a new user account
`GET /api/v1/users/{userId}` - Retrieve details of a specific user by ID
`PUT /api/v1/users/{userId}` - Update the details of an existing user by ID
`DELETE /api/v1/users/{userId}` - Delete a user account by ID

### Request Parameters

#### Create User (POST)

| Parameter   | Data Type | Description                                     |
|-------------|----------|-------------------------------------------------|
| `name`      | string   | The name of the user.                           |
| `email`     | string   | A unique email address for the user.            |
| `password`  | string   | The password for the new user account.          |
| `role`      | string   | The role assigned to the user (e.g., admin, user). |

#### Retrieve User (GET)

| Parameter | Data Type | Description                             |
|-----------|----------|-----------------------------------------|
| `userId`  | integer  | The unique ID of the user to retrieve.   |

#### Update User (PUT)

| Parameter   | Data Type | Description                                      |
|-------------|----------|--------------------------------------------------|
| `name`      | string   | The updated name of the user.                    |
| `email`     | string   | An updated email address for the user (optional).  |
| `password`  | string   | An updated password for the user (optional).      |
| `role`      | string   | An updated role assigned to the user (optional).   |

#### Delete User (DELETE)

No parameters are required in this request. The user is deleted based on the provided ID.

### Response Parameters

#### Successful Responses

All successful responses use a JSON format and include the following properties:

| Property  | Data Type | Description                             |
|-----------|----------|-----------------------------------------|
| `status`  | string   | The status of the request (e.g., success). |
| `data`    | object   | The data associated with the request.     |

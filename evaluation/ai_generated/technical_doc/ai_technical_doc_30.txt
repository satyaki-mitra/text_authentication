Title: API Documentation - User Management REST Endpoint

## User Management REST Endpoint

### Description

This document outlines the User Management REST endpoint for our API. It provides details on how to interact with user-related resources, including creating, retrieving, updating, and deleting users.

### Endpoints

#### Create User (POST)

```
https://api.example.com/users
```

Creates a new user in the system.

#### Retrieve User (GET)

```
https://api.example.com/users/{user_id}
```

Retrieves details for a specific user by ID.

#### Update User (PUT)

```
https://api.example.com/users/{user_id}
```

Updates the details of an existing user by ID.

#### Delete User (DELETE)

```
https://api.example.com/users/{user_id}
```

Deletes a specific user by ID from the system.

### Request Parameters

| Parameter         | Data Type     | Description                                                                    |
|-------------------|---------------|------------------------------------------------------------------------------|
| `user_id`          | `string`      | (Optional, Get/Delete) The unique identifier for a user in the system.       |
| `name`             | `string`      | (POST/PUT) The name of the user.                                            |
| `email`            | `string`      | (POST/PUT) The email address of the user.                                   |
| `password`         | `string`      | (POST) The password for the new user.                                        |
| `role`             | `string`      | (Optional, PUT) The role of the user (e.g., 'admin', 'user').               |

### Response Parameters

| Parameter         | Data Type     | Description                                                                    |
|-------------------|---------------|------------------------------------------------------------------------------|
| `status_code`     | `integer`     | The HTTP status code (e.g., 200 for success, 4xx/5xx for errors).            |
| `data`            | `object`      | (Optional) The data returned with the response (e.g., user details in GET).   |
| `message`         | `string`      | A message describing the result of the request (e.g., 'User created successfully').|
| `errors`          | `array`       | (Optional, POST/PUT) An array of error messages if validation fails or an error occurs.|

Title: API Documentation - User Management Endpoint

## User Management REST Endpoint

### Description

This API provides endpoints for managing user accounts within the system. The primary focus is on creating, retrieving, updating, and deleting user records.

### Authentication Requirements

All requests to this endpoint require a valid JWT token in the `Authorization` header. The token should be sent as `Bearer token`.

### Endpoints

#### Create User

**Endpoint:** POST /api/users

**Request Parameters**

| Parameter      | Data Type  | Description                                             |
|---------------|-----------|---------------------------------------------------------|
| name          | string    | The user's full name                                    |
| email         | string    | A unique email address for the user                     |
| password      | string    | The user's password (hashed before storage)            |
| role           | enum      | The user's role within the system ('admin', 'user')   |

#### Retrieve User

**Endpoint:** GET /api/users/{id}

**Request Parameters**

| Parameter | Data Type | Description                        |
|-----------|----------|------------------------------------|
| id        | integer  | The unique identifier for the user |

#### Update User

**Endpoint:** PUT /api/users/{id}

**Request Parameters**

| Parameter | Data Type  | Description                                             |
|---------------|-----------|---------------------------------------------------------|
| id          | integer    | The unique identifier for the user                      |
| name        | string    | The user's updated full name                           |
| email       | string    | The user's updated email address (if it changes)      |
| role         | enum      | The user's new role within the system ('admin', 'user')|

#### Delete User

**Endpoint:** DELETE /api/users/{id}

**Request Parameters**

| Parameter | Data Type | Description                        |
|-----------|----------|------------------------------------|
| id        | integer  | The unique identifier for the user |

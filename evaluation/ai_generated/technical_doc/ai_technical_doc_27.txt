Title: API Documentation - User Management Endpoint

## User Management REST Endpoint

### Description

This API provides a set of endpoints for managing user-related operations such as registration, login, profile update, and account deletion. The primary endpoint is `/api/v1/users`, which serves as the base for all user management operations.

### Authentication Requirements

Most of the operations in this API require proper authentication. Use the `Authorization` header with a JWT token to authenticate your requests. The token should be included as follows:

```bash
Authorization: Bearer {your_token}
```

### Endpoints

#### 1. User Registration

- **Endpoint:** `POST /api/v1/users/register`

- **Request Parameters:**

  - `name` (string, required)
  - `email` (string, required, unique)
  - `password` (string, SHA-256 hashed, required)

- **Response Parameters:**

  - `status` (integer, success or error code)
  - `message` (string, status message)
  - `data` (object, user details on success)

#### Example Request:

```bash
curl -X POST \
  'http://your-api-url.com/api/v1/users/register' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "John Doe",
    "email": "johndoe@example.com",
    "password": "hashed_password"
  }'
```

#### Error Codes:

- **400 Bad Request:** Invalid or missing parameters
- **409 Conflict:** Email already exists
- **500 Internal Server Error:** Unhandled errors

#### Usage Notes:

The password should be hashed using SHA-256 before sending the request.

Title: PetStore API - Find Pets by Status

## Endpoint Description

This API is used to retrieve a list of pets that match the given status. The endpoint uses the `GET` HTTP method and conforms to REST architecture principles.

## Request Parameters

The API accepts query parameters for filtering pets by their status.

Parameter | Data Type | Description
-----------|----------|------------
`status`   | string   | Status of the pet (available, sold)

## Authentication Requirements

Access to this endpoint requires an API key in the `Authorization` header. The API key can be obtained by registering for a developer account at [PetStore](https://petstore.swagger.io/).

Example:
```
Authorization: Bearer {your_api_key}
```

## Example Requests

A request to retrieve all pets with status "available" would look like this:

Request URL: `https://petstore.swagger.io/v2/pet/findByStatus?status=available`

Request Headers:
```
Content-Type: application/json
Authorization: Bearer {your_api_key}
```

## Response Parameters

The API response is a JSON object containing an array of pets that match the requested status. Each pet object has the following properties:

Property | Data Type | Description
---------|----------|------------
`id`      | integer  | The unique identifier for the pet
`category` | object   | Pet category details (not provided in this response)
`name`    | string   | Name of the pet
`photoUrls` | array   | An array of URLs to images of the pet
`tags`    | array   | Tags associated with the pet
`status`  | string   | Current status of the pet (available, sold)

## Example Response

```json
{
  "petId": 12345,
  "category": {
    "id": 4,
    "name": "dog"
  },
  "name": "Max",
  "photoUrls": [
    "string"

  "tags": [
```

## Error Codes

Error responses will include the following properties:

Property | Data Type | Description
---------|----------|------------
`code`   | integer  | Error code as defined in [RFC 6838](https://tools.ietf.org/html/rfc683

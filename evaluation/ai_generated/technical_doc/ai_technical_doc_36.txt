Title: API Documentation - User Management Endpoint

## User Management API

### Endpoint Description

This API provides endpoints for managing users within the system. The primary focus is on CRUD (Create, Read, Update, Delete) operations related to user accounts.

### Authentication Requirements

All requests to this endpoint require authentication using a JSON Web Token (JWT). The token should be included in the `Authorization` header with the prefix `Bearer`.

### Endpoints

#### 1. Create User

**Endpoint:** `POST /api/users`

**Request Parameters:**

- `name`: Required. User's full name (string).
- `email`: Required. Unique user email address (string).
- `password`: Required. User's password (string). Password should be encrypted before sending the request.

**Example Request:**

```
POST /api/users HTTP/1.1
Content-Type: application/json
Authorization: Bearer <JWT_TOKEN>

{
  "name": "John Doe",
  "email": "johndoe@example.com",
  "password": "<encrypted_password>"
}
```

**Response:**

- `201 Created`: Successful creation of the user with a generated API key.
- `400 Bad Request`: Invalid input data or missing required parameters.
- `409 Conflict`: The provided email address is already registered.

#### 2. Get User Details

**Endpoint:** `GET /api/users/{userId}`

**Request Parameters:**

- `userId`: Required. Unique identifier of the user (integer).

**Example Request:**

```
GET /api/users/1 HTTP/1.1
Authorization: Bearer <JWT_TOKEN>
```

**Response:**

- `200 OK`: Successful retrieval of the user details.
- `400 Bad Request`: Invalid input data or missing required parameters.
- `404 Not Found`: The specified user does not exist.

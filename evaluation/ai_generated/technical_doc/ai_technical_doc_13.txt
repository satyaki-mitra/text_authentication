Title: Product Management API - Get Products

## Description

The `GET /products` endpoint provides a way to retrieve a list of all available products in the system. This is a read-only operation that does not modify any data within the system.

## Authentication Requirements

To access this endpoint, you must include an API key in the `Authorization` header of your request. The API key should be provided to you upon registration or account setup with our service.

Example:

```
Authorization: Bearer <Your_API_Key>
```

## Request Parameters

This endpoint does not require any specific request parameters. However, you can optionally filter the results by using query parameters:

- `limit` (optional, integer): Specify the maximum number of items to return per page. Default value is 20. Maximum value is 100.
- `offset` (optional, integer): Skip a specified number of items in the results. Default value is 0.
- `sort_by` (optional, string): Sort the results by a specific product attribute. Supported attributes include: `id`, `name`, `price`, and `created_at`. Default sorting order is ascending. To sort in descending order, append `desc` to the attribute name, like so: `sort_by=price_desc`.

## Response Parameters

The response will be a JSON array containing objects representing each product. Each object includes the following properties:

- `id` (integer): Unique identifier for the product.
- `name` (string): The name of the product.
- `description` (string): A brief description of the product.
- `price` (float): The current price of the product, in USD.
- `created_at` (string, format YYYY-MM-DD HH:MM:SS): The date and time when the product was created.

Example Response:

```json
[
  {
    "id": 1,
    "name": "Product A",
    "description": "This is Product A.",
    "price": 9.99,
    "created_at": "2022-01-01 12:34:56"
  },
  {
    "id": 2,
    "name": "Product B",
    "description": "This is Product B.",
    "price": 19.99,
    "created_at": "2022-01-01 15:37:23"
  }
]
```

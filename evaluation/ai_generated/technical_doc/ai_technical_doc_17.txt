Title: API Documentation - User Management Endpoint

## User Management REST Endpoint

### Description

This API provides a RESTful interface for managing user accounts within our system. The primary endpoints are focused on creating, reading, updating, and deleting users. Authentication is required to access these functionalities.

### Endpoint

`https://api.example.com/v1/users`

### Request Parameters

#### Create User (POST)

```json
{
  "username": "string",
  "email": "string",
  "password": "string",
  "first_name": "string",
  "last_name": "string"
}
```

#### Read User (GET)

```
/users/{user_id}
```

#### Update User (PUT)

```json
{
  "username": "string",
  "email": "string",
  "password": "string",
  "first_name": "string",
  "last_name": "string"
}
```

#### Delete User (DELETE)

```
/users/{user_id}
```

### Response Parameters

#### Successful Responses

All successful responses will have the following structure:

```json
{
  "status": "success",
  "data": {
    // Response specific data, e.g., user object for GET requests
  }
}
```

#### Error Responses

All error responses will have the following structure:

```json
{
  "status": "error",
  "code": "string",
  "message": "string"
}
```

##### Error Codes

- `INVALID_REQUEST`: The request is missing required parameters or contains invalid data.
- `USER_NOT_FOUND`: The requested user does not exist in the system.
- `AUTHENTICATION_FAILED`: Authentication credentials are invalid or expired.
- `INTERNAL_SERVER_ERROR`: An unexpected error occurred on our server. Please try again later.

### Authentication Requirements

All requests, except for logging in (see below), require a valid API token to be included in the `Authorization` header. The token should be in the format: `Bearer {your_token}`.

For obtaining an API token, please use the authentication endpoint:

```bash
POST https://api.example.com/v1/auth/login

{
  "username": "string",
  "password": "string"
}
```

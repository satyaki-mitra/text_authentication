Title: API Documentation - User Management Endpoint

## User Management REST Endpoint

### Description

This API provides endpoints for managing user accounts within our application. The main functionalities include creating, retrieving, updating, and deleting user accounts. All operations are performed over the HTTPS protocol to ensure data security.

### Authentication Requirements

All requests to this endpoint require a valid API key for authentication. The API key should be included in the `Authorization` header with the prefix `Bearer`. For example:

```
Authorization: Bearer <your_api_key>
```

### Endpoints

#### 1. Create User (POST /users)

Creates a new user account.

**Request Parameters**

| Parameter         | Data Type          | Description                                                             |
|-------------------|--------------------|-------------------------------------------------------------------------|
| name              | String             | The user's full name                                                    |
| email             | String             | A unique email address for the user                                     |
| password          | String             | The user's chosen password (encrypted before storage)                  |
| role              | Enum ('admin', 'user') | The user's role within the application (either admin or regular user) |

**Response Parameters**

| Parameter         | Data Type          | Description                               |
|-------------------|--------------------|-------------------------------------------|
| id                | Integer            | The created user's unique identifier      |
| name              | String             | The user's full name                       |
| email             | String             | The user's email address                   |
| role              | Enum ('admin', 'user')| The user's role within the application    |

**Example Request**

```bash
POST /users HTTP/1.1
Content-Type: application/json
Authorization: Bearer <your_api_key>

{
  "name": "John Doe",
  "email": "john.doe@example.com",
  "password": "<encrypted_password>",
  "role": "user"
}
```

**Error Codes**

| Code   | Description                         |
|--------|-------------------------------------|
| 401    | Unauthorized: Invalid or missing API key |
| 409    | Conflict: Email address already in use |

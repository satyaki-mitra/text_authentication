Title: Documentation on Observer Design Pattern with Java Implementation

## Introduction

The Observer Design Pattern is a behavioral design pattern that defines a one-to-many dependency between objects such that when one object changes state, all its dependents are notified and updated automatically. This pattern is particularly useful in implementing event-driven systems, real-time applications, or any scenario where there's a need for inter-object communication without the objects explicitly calling each other.

## Use Cases

1. **Weather Forecasting System:** In this system, weather data is collected by weather instruments and sent to the display system. When there are changes in weather conditions, the Observer pattern allows the display system to be automatically updated.

2. **Stock Market Application:** In a stock market application, multiple users can subscribe to stock updates. Whenever the price of a stock changes, all subscribed users receive an update.

## Java Implementation

### Interface Definition

```java
public interface Subject {
    void attach(Observer observer);
    void detach(Observer observer);
    void notifyObservers();
}
```

```java
public interface Observer {
    void update(Subject subject);
}
```

### Concrete Subject Implementation

```java
import java.util.*;

public class WeatherData implements Subject, Observable {
    private float temperature;
    private float humidity;
    private float pressure;
    private List<Observer> observers = new ArrayList<>();

    public void measurementsChanged() {
        notifyObservers();
    }

    @Override
    public void attach(Observer observer) {
        observers.add(observer);
        observer.update(this);
    }

    @Override
    public void detach(Observer observer) {
        observers.remove(observer);
    }

    @Override
    public void notifyObservers() {
        for (Observer observer : observers) {
            observer.update(this);
        }
    }

    // Other methods to set and get measurements
}
```

Title: Understanding the Functional Programming Pattern - Map, Reduce, and Filter in JavaScript

Functional Programming (FP) is a programming paradigm that emphasizes the use of functions as first-class citizens and immutability to solve problems. One of its popular techniques is the Map, Reduce, and Filter (MRF) pattern, which helps in handling collections effectively without mutating them. In this article, we will explore these three methods in JavaScript.

1. **Map**
   Map is a higher-order function that applies a provided function to each element of an array or other iterable object and returns a new array with the results. The original data remains unchanged.

```javascript
const numbers = [1, 2, 3, 4, 5];
const squaredNumbers = numbers.map(num => num * num);
console.log(squaredNumbers); // Output: [1, 4, 9, 16, 25]
```

2. **Reduce**
   Reduce is another higher-order function that reduces an array or iterable object to a single value by iteratively applying a provided function to the accumulator and each element in the array, starting from an optional initialValue.

```javascript
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce((total, num) => total + num, 0);
console.log(sum); // Output: 15
```

3. **Filter**
   Filter is a higher-order function that creates a new array with all elements that pass the test provided by the callback function. It does not modify the original data.

```javascript
const numbers = [1, 2, 3, 4, 5];
const evenNumbers = numbers.filter(num => num % 2 === 0);
console.log(evenNumbers); // Output: [2, 4]
```

By using Map, Reduce, and Filter, you can write more concise and maintainable code in JavaScript by adhering to the principles of functional programming. These methods are essential tools for any developer working with arrays or iterable objects in modern JavaScript projects.

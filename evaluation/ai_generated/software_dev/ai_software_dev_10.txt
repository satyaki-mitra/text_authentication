Title: Understanding Functional Programming in JavaScript with the Map, Reduce, and Filter Methods

Functional programming is a programming paradigm that emphasizes the use of functions as first-class citizens, immutable data, and avoiding side effects (changes to external state). In this article, we will explore three powerful methods in JavaScript – `map`, `reduce`, and `filter` – that are essential tools for functional programming.

1. Map: The map() method is used to create a new array with the results of calling a provided function on every element in the array. It does not modify the original array but instead returns a new one. Here's an example:

```javascript
const numbers = [1, 2, 3, 4, 5];
const squares = numbers.map(num => num * num); // [1, 4, 9, 16, 25]
```
In this example, we created a new array of square numbers without modifying the original `numbers` array.

2. Reduce: The reduce() method applies a provided function against an accumulator and each element in the array (from left to right) to reduce it to a single output value. Here's an example that calculates the sum of all elements in an array:

```javascript
const numbers = [1, 2, 3, 4, 5];
const sum = numbers.reduce((total, num) => total + num, 0); // 15
```
In this example, we start with an initial value of `0` and add each number in the array to the accumulator (`total`) until we get the final result, `15`. The reduce() method is also useful for other operations like finding the minimum or maximum values in an array.

3. Filter: The filter() method creates a new array with all elements that pass the test provided by the function. It does not modify the original array but instead returns a new one. Here's an example that filters out odd numbers from an array:

```javascript
const numbers = [1, 2, 3, 4, 5];
const evens = numbers.filter(num => num % 2 === 0); // [2, 4]
```

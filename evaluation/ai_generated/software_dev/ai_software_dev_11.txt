Title: Documentation on Dependency Injection in Java using Spring Framework

Introduction:

Dependency Injection (DI) is a software design pattern that allows the removal of hardcoded dependencies by an external entity at runtime. This promotes loose coupling, makes code more testable, and simplifies application maintenance. This documentation focuses on Dependency Injection in Java using the Spring Framework.

Prerequisites:

- Basic understanding of Object-Oriented Programming (OOP) concepts.
- Familiarity with Java programming language.
- Knowledge of Maven or Gradle for project setup and dependency management.
- Understanding of Spring Framework (Spring Core, Spring Beans, Autowiring).

Setup:

To get started, first set up a new Maven project in your IDE of choice. Add the Spring Web and Spring Context dependencies to your `pom.xml`.

```xml
<dependencies>
    <dependency>
        <groupId>org.springframework</groupId>
        <artifactId>spring-webmvc</artifactId>
        <version>5.3.20</version>
    </dependency>
    <dependency>
        <groupId>org.springframework</groupId>
        <artifactId>spring-context</artifactId>
        <version>5.3.20</version>
    </dependency>
</dependencies>
```

Create a simple controller with a dependency on a service class:

```java
package com.example.demo;

import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;

@Controller
public class SimpleController {
    private final SimpleService simpleService;

    public SimpleController(SimpleService simpleService) {
        this.simpleService = simpleService;
    }

    @GetMapping("/")
    public String greet(Model model) {
        model.addAttribute("greeting", simpleService.getGreeting());
        return "greeting";
    }
}
```

In the code above, `SimpleController` depends on a `SimpleService`. To apply Dependency Injection, we'll need to configure Spring Beans for both classes.

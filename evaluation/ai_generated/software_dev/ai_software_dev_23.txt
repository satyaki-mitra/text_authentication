Title: Documentation on Dependency Injection in C# using Constructor Injection

Dependency Injection (DI) is a software design pattern that separates the construction of an object from its behavior, thus improving modularity, testability, and maintainability. This document explains the implementation of Dependency Injection using Constructor Injection in C#.

**Use Case**

Consider a simple example: A `DatabaseService` class that requires an instance of `IDatabaseConnection` to perform its operations. Instead of hardcoding the dependency within the `DatabaseService`, we can use Dependency Injection to inject the required dependency at runtime.

```csharp
public interface IDatabaseConnection
{
    void Connect();
}

public class SqlServerConnection : IDatabaseConnection
{
    public void Connect()
    {
        Console.WriteLine("Connected to SQL Server");
    }
}

public class DatabaseService
{
    private readonly IDatabaseConnection _connection;

    public DatabaseService(IDatabaseConnection connection)
    {
        _connection = connection;
    }

    public void PerformOperations()
    {
        _connection.Connect();
        // Other operations...
    }
}
```

In the above example, `DatabaseService` is constructed with an instance of `IDatabaseConnection`. This way, we can easily swap the concrete implementation (e.g., replace `SqlServerConnection` with `MySQLConnection`) without modifying `DatabaseService`.

**Implementation: Container and Registration**

To manage the dependencies and their instantiation, we use a DI container like Microsoft's `SimpleInjector`. First, install it via NuGet package. Then, register the required services and their dependencies with the container during application startup.

```csharp
var container = new Container();
container.Register<IDatabaseConnection, SqlServerConnection>();
container.Register<DatabaseService>(Lifestyle.Transient);
```

**Use of DI Container in Service Construction**

To inject the dependencies during service construction, we use the `container.GetInstance<T>()` method while creating an instance of our services, such as `DatabaseService`.

```csharp
public class Program
{
    static void Main(string[] args)
    {
        var container = new Container();
        container.Register<IDatabaseConnection, SqlServerConnection>();
        container.Register<DatabaseService>(Lifestyle.Transient);

        var databaseService = container.GetInstance<DatabaseService>();
        databaseService.PerformOperations();
    }
}
```
